## 本地运行与测试

> 当前仓库是纯前端页面（`index.html`），需要用本地静态服务器打开，不能直接在终端里“看到网页”。

### 1) 启动本地服务器
在仓库根目录执行：

```bash
python3 -m http.server 8080
```

看到类似输出表示启动成功：

```text
Serving HTTP on 0.0.0.0 port 8080
```

### 2) 在浏览器打开
访问：

- `http://localhost:8080/index.html`

如果你在远程/容器环境，需要把 8080 端口映射到本机后再访问。

### 3) 功能测试清单

#### 基础渲染
- 页面标题显示“个体深层画像分析网页（接入AI模型）”。
- 能看到 API 配置区、输入区、结果区、状态区。

#### 本地降级测试（不填 API Key）
1. `无 Key 时策略` 选择“自动降级到本地模板分析”。
2. 任意填写输入项，点击“生成分析（优先AI）”。
3. 预期：状态显示“AI失败，已降级本地分析...”，且六个分析模块有文本输出。

#### 严格模式测试（不填 API Key）
1. `无 Key 时策略` 选择“严格要求AI接口（无Key则报错）”。
2. 点击“生成分析（优先AI）”。
3. 预期：状态显示“AI失败：缺少 API Key”。

#### AI 接口联调测试
1. 填写 `API Base URL`（如 `https://your-api/v1`）、`模型名`、`API Key`。
2. 点击“生成分析（优先AI）”。
3. 预期：状态显示“AI分析完成”，结果区输出 6 个结构化模块。

#### 重置测试
- 点击“清空输入”，预期输入被清空，结果恢复默认占位，状态显示“已重置”。

## 常见问题

### 为什么“看不到网页”？
- 终端只能显示日志，不能直接渲染 HTML。
- 需要浏览器访问 `http://localhost:8080/index.html`。

### API 调不通怎么办？
- 先确认 Base URL 末尾是否包含 `/v1`。
- 确认接口是否兼容 `POST /chat/completions`。
- 确认鉴权是否为 `Authorization: Bearer <API_KEY>`。
